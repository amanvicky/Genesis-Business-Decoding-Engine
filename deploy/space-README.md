# Genesis — live demo

Paste a company name, its website URL, or a raw idea, and Genesis assembles a
19-tab intelligence brief: feasibility, compliance, pricing math, burn and
runway, distribution, market sizing, public registration records, and a
red-team review — every claim linked to its source.

**This is the evidence-thin demo.** Genesis is designed to run on YOUR machine
(see the [repo](https://github.com/amanvicky/Genesis-Business-Decoding-Engine))
where its honest, polite scrapers work at full strength. Search engines rate-
limit shared cloud IPs hard, so some live-evidence lanes (surface search,
LinkedIn, press) may return little here. The knowledge-base layer — compliance
matrices, failure post-mortems, distribution loops, market math, scaffolding —
is fully intact, as are RDAP/EDGAR/Wayback.

No API keys. No accounts. When you install it locally, everything stays on
your machine.
